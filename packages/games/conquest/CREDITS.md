# conquest: credits

Every asset and content source with its license (SPEC §19).

- **Rules:** an original game of territory for kefche, in the long tradition of map-and-dice war games, which nobody owns. The map, its regions, the supply rule and the look are kefche's own; no names, maps or cards from any published game.
- **Map:** drawn in code for kefche (`engine/map.ts`, `renderer/Game.tsx`).
- **Dice:** the SDK's dice, drawn in code.
- **Art:** drawn in code for kefche (`assets/art.mjs`, with `scripts/game-art/kit.mjs`).
- **Sounds:** synthesized in code by the shared game SDK (`packages/game-sdk/src/browser/synth.ts`); no recordings or third-party audio.

No third-party assets.
