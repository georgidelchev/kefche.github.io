# trivia: credits

Every asset and content source with its license (SPEC §19).

- **Rules:** the quiz with four answers and points for speed, a format nobody owns; the scoring, the levels and the design are kefche's own.
- **Questions** (`content/en.json`, `content/bg.json`): written for kefche (Phase 13 Q3), 240 in each language, the same questions in both, in eight categories and three levels; released with the project. Each English question names, under `checked`, the encyclopedia topic its answer was checked against (Encyclopaedia Britannica and Wikipedia). More languages come with Phase 15.
- **Art:** drawn in code for kefche (`assets/art.mjs`, with `scripts/game-art/kit.mjs`).
- **Sounds:** synthesized in code by the shared game SDK (`packages/game-sdk/src/browser/synth.ts`); no recordings or third-party audio.

No third-party assets.
