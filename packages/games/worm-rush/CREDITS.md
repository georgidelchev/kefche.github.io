# worm-rush: credits

The rules, the bots, the arena drawing, the controls, the skins and the graphics were made for kefche. Worm Rush shares its genre with other arena worm games; it uses no code, art, names or sounds from any of them.

## Libraries

- **PixiJS** 8.22.0 (MIT), which draws the arena: <https://pixijs.com/>.

## Sounds

Synthesized in code by the shared game SDK (packages/game-sdk/src/browser/synth.ts); no recordings or third-party audio.
