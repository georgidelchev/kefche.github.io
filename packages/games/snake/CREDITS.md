# snake: credits

The rules implementation, the board drawing, the controls and the graphics were made for kefche. Snake is a traditional arcade game; this implementation uses no code or art from any existing version.

## Sounds

By Kenney (www.kenney.nl), released under **CC0 1.0** (public domain), converted from OGG to mono MP3 with trailing silence trimmed:

| ------------------------ | ------------------------------------------- |

| `assets/sounds/lose.mp3` | Music Jingles, Pizzicato, `jingles_PIZZI12` |
