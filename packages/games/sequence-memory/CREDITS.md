# sequence-memory: credits

Every asset and content source with its license (SPEC §19).

- **Rules:** repeating a growing sequence of lights and sounds is a traditional memory game that nobody owns; the name, pads, shapes and design are kefche's own, and no other game's name, look or sounds are used.
- **Colours:** the pads use the Okabe–Ito colour-blind-safe palette (Okabe and Ito, 2002, free to use), each also with its own shape and sound.
- **Art:** drawn in code for kefche (`assets/art.mjs`, with `scripts/game-art/kit.mjs`).
- **Sounds:** synthesized in code by the shared game SDK (`packages/game-sdk/src/browser/synth.ts`); no recordings or third-party audio.

No third-party assets.
