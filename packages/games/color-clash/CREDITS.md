# color-clash: credits

Every asset and content source with its license (SPEC §19).

- **Rules:** the Stroop effect (J. R. Stroop, 1935), a classic of psychology that nobody owns; the name, scoring and design are kefche's own.
- **Colours:** the four inks are from the Okabe–Ito colour-blind-safe palette (Okabe and Ito, "Color Universal Design", 2002, free to use), checked here with the dataviz palette validator.
- **Art:** drawn in code for kefche (`assets/art.mjs`, with `scripts/game-art/kit.mjs`).
- **Sounds:** synthesized in code by the shared game SDK (`packages/game-sdk/src/browser/synth.ts`); no recordings or third-party audio.

No third-party assets.
