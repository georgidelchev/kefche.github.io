# whos-the-spy: credits

Every asset and content source with its license (SPEC §19).

- **Rules:** the traditional party game of a spy among people who share a secret place, which nobody owns. kefche's version is its own: locations only, one round, a vote, and the spy's guess.
- **Location packs** (`content/en.json`, `content/bg.json`): written for kefche, 30 everyday places in each language, kefche's own selection, released with the project. More languages come with Phase 15.
- **Layout:** drawn in code for kefche (`renderer/Game.tsx`).
- **Art:** drawn in code for kefche (`assets/art.mjs`, with `scripts/game-art/kit.mjs`).
- **Sounds:** synthesized in code by the shared game SDK (`packages/game-sdk/src/browser/synth.ts`); no recordings or third-party audio.

No third-party assets.
