- **Rules:** spotting the one item that differs is a traditional puzzle that nobody owns. The rings with a gap follow the Landolt ring used in eye tests (Edmund Landolt, 1888), a public-domain shape; the name, levels and scoring are kefche's own.
- **Art:** drawn in code for kefche (`assets/art.mjs`, with `scripts/game-art/kit.mjs`).
- **Sounds:** synthesized in code by the shared game SDK (`packages/game-sdk/src/browser/synth.ts`); no recordings or third-party audio.
