# categories: credits

Every asset and content source with its license (SPEC §19).

- **Rules:** the traditional pencil-and-paper game of naming things that start with a letter (played as Categories, Stop and, in Bulgaria, "Държави и градове"), which nobody owns; the eight categories, the voting, the scoring and the design are kefche's own.
- **Known answers** (`content/en.json`, `content/bg.json`): written for kefche, eight categories in each language (every country, plus cities, animals, plants, food, first names, jobs and things at home), and the letters each language plays with; released with the project. More languages come with Phase 15.
- **Word lists** (the blocklist, and the bots' votes): the shared lists in `packages/lexicons` (ENABLE, public domain; BgOffice, MPL 1.1), with their credits in `packages/lexicons/CREDITS.md`.
- **Art:** drawn in code for kefche (`assets/art.mjs`, with `scripts/game-art/kit.mjs`).
- **Sounds:** synthesized in code by the shared game SDK (`packages/game-sdk/src/browser/synth.ts`); no recordings or third-party audio.

No third-party assets beyond the word lists above.
