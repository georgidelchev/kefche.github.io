# anagrams: credits

Every asset and content source with its license (SPEC §19).

- **Rules:** making words from a set of letters is a traditional word game nobody owns; the name, scoring and design are kefche's own.
- **Seed words** (`content/en.json`, `content/bg.json`): English, the common seven-letter words of the shared lists (SCOWL, `packages/lexicons`) that hold at least 30 shorter words; Bulgarian, chosen for kefche and checked against the dictionary. Released with the project.
- **Dictionary:** the shared word lists in `packages/lexicons` (ENABLE, public domain; SCOWL; BgOffice, MPL 1.1), with their credits in `packages/lexicons/CREDITS.md`.
- **Art:** drawn in code for kefche (`assets/art.mjs`, with `scripts/game-art/kit.mjs`).
- **Sounds:** synthesized in code by the shared game SDK (`packages/game-sdk/src/browser/synth.ts`); no recordings or third-party audio.

No third-party assets beyond the word lists above.
